# RS485 压力变送器 Modbus-RTU 协议开发手册

## 1. 通信基础配置 (Communication Basics)
- **协议标准**: Modbus-RTU
- **物理媒介**: RS485
- **字节序 (Byte Order)**: **大端模式 (Big-Endian)**，即高字节在前，低字节在后。（*注：CRC校验码除外，CRC为低字节在前*）。
- **数据类型**: 16位寄存器 (2 Bytes)。多字节数据（如32位浮点数）按高字在前、低字在后排列。
- **CRC校验**: CRC-16/MODBUS，多项式 `0xA001`，初始值 `0xFFFF`。
- **默认串口参数**: 波特率 9600, 8数据位, 无校验(NONE), 1停止位。
- **从机地址**: 1~255 (默认 1)。
- **帧间隔**: 消息开始和结束依靠 >= 3.5个字符的静默时间间隔识别。
- **性能限制**: 单次读取寄存器数量**不得超过 15 个**，否则可能导致数据异常。

## 2. 寄存器映射字典 (Register Map)
*说明：地址为16进制，数据类型若无特殊说明均为 `UINT16` 或 `INT16`。*

| 寄存器地址 (Hex) | 寄存器地址 (Dec) | 读写 | 数据类型 | 数据含义与解析规则 |
| :--- | :--- | :--- | :--- | :--- |
| `0x0000` | 0 | R/W | UINT16 | **从机地址** (1-255) |
| `0x0001` | 1 | R/W | UINT16 | **波特率索引** (0:1200, 1:2400, 2:4800, 3:9600, 4:19200, 5:38400, 6:57600, 7:115200) |
| `0x0002` | 2 | R | UINT16 | **压力单位** (见下方单位映射表) |
| `0x0003` | 3 | R | UINT16 | **小数点位数** (0~4，代表 10^0 到 10^4) |
| `0x0004` | 4 | R | **INT16** | **压力测量值 (整型)**。需结合 `0x0003` 进行浮点转换。 |
| `0x0005` | 5 | R | INT16 | 压力变送器量程零点 (校准参数，勿改) |
| `0x0006` | 6 | R | INT16 | 压力变送器量程满点 (校准参数，勿改) |
| `0x000C` | 12 | R/W | INT16 | **零位偏移值**。实际输出值 = 校准测量值 + 零位偏移值 |
| `0x0016` | 22 | R | **FLOAT32** | **压力测量值 (浮点型)**。占用2个寄存器(`0x0016`, `0x0017`)，IEEE754大端格式。 |
| `0x001A` | 26 | R/W | UINT16 | **显示值系数** (100-9900，默认1000)。实际系数 = 寄存器值 / 1000 |
| `0x0025` | 37 | R/W | UINT16 | **串口校验位** (0:NONE, 1:ODD, 2:EVEN) |
| `0x000F` | 15 | W | UINT16 | **保存到用户区** (写入 `0x0000` 触发保存，断电不保存则数据丢失) |
| `0x0010` | 16 | W | UINT16 | **恢复工厂参数** (写入 `0x0001` 触发恢复) |

## 3. 核心数据解析算法 (Data Parsing Logic)

### 3.1 整型测量值解析 (寄存器 0x0004)
1. **读取原始数据**：获取2字节数据，按**大端模式**拼接为16位整数。
2. **符号处理**：该数据为**有符号16位整数 (INT16)**。范围 `-32768 ~ 32767` (Hex: `0x8000 ~ 0x7FFF`)。
   * *示例*：读取到 `0xFF9C`，转换为十进制为 `-100`。
3. **真实物理值计算**：
   ```python
   # 伪代码
   raw_int16 = parse_int16_big_endian(bytes)
   decimal_point = read_register(0x0003) # 0, 1, 2, 3, 或 4
   real_value = raw_int16 / (10 ** decimal_point)
   ```
   * *示例*：`0x0003`读出为2（2位小数），`0x0004`读出为1001。真实值 = `1001 / 10^2 = 10.01`。

### 3.2 浮点型测量值解析 (寄存器 0x0016)
1. **读取原始数据**：连续读取2个寄存器（共4字节），地址为 `0x0016` 和 `0x0017`。
2. **字节序**：IEEE754 **大端格式 (Big-Endian)**，即 `0x0016` 为高16位，`0x0017` 为低16位。
3. **转换**：将4字节直接按 IEEE754 标准解析为 32位浮点数 (Float32)。

## 4. 报文帧结构 (Frame Structure)

### 4.1 读寄存器 (功能码 0x03 / 0x04)
**主站请求 (8 Bytes):**
| 字节1    | 字节2     | 字节3-4       | 字节5-6         | 字节7-8  |
| :------- | :-------- | :------------ | :-------------- | :------- |
| 从机地址 | 0x03/0x04 | 起始地址(H+L) | 寄存器数量(H+L) | CRC(L+H) |

**从站正常响应:**
| 字节1    | 字节2     | 字节3         | 字节4~N          | 最后2字节 |
| :------- | :-------- | :------------ | :--------------- | :-------- |
| 从机地址 | 0x03/0x04 | 数据字节数(N) | 寄存器数据(大端) | CRC(L+H)  |

### 4.2 写单个寄存器 (功能码 0x06)
**主站请求 (8 Bytes):**
| 字节1    | 字节2 | 字节3-4         | 字节5-6       | 字节7-8  |
| :------- | :---- | :-------------- | :------------ | :------- |
| 从机地址 | 0x06  | 寄存器地址(H+L) | 写入数据(H+L) | CRC(L+H) |

**从站正常响应:** 原样返回主站请求帧。

### 4.3 异常响应
| 字节1                                                        | 字节2           | 字节3  | 字节4-5  |
| :----------------------------------------------------------- | :-------------- | :----- | :------- |
| 从机地址                                                     | 0x80 + 原功能码 | 异常码 | CRC(L+H) |
| *异常码: `0x01` 非法功能, `0x02` 非法数据地址, `0x03` 非法数据。* |                 |        |          |

## 5. 注意事项

1. **保存机制 (极其重要)**：
   用户允许修改的参数仅有：`地址(0x0000)`、`波特率(0x0001)`、`校验位(0x0025)`、`零位偏移(0x000C)`、`显示系数(0x001A)`。
   **规则**：任何修改参数的操作后，**必须**向寄存器 `0x000F` 写入 `0x0000` 以保存到EEPROM，否则断电丢失。
2. **地址修改逻辑**：
   修改地址时，从机会用**旧地址**回复确认帧，回复完成后才切换到**新地址**。编程时需处理此异步状态。
3. **波特率修改逻辑**：
   修改波特率时，从机会用**旧波特率**回复确认帧，回复完成后立即切换到**新波特率**。主机需在收到回复后同步切换串口波特率。
4. **PLC地址偏移**：
   若代码用于西门子等PLC的Modbus库，寄存器地址需加上 `40001` 偏移（例如：读 `0x0004` 需请求 `40005`）。若使用标准Modbus TCP/RTU库或串口调试助手，则**不加偏移**，直接使用 `0x0004`。
5. **禁止越权操作**：
   禁止向校准参数（如 `0x0005`, `0x0006` 等）写入数据，否则从机会返回异常码 `0x03`。

## 6. 交互示例 (Hex Examples)

### 示例 1：读取当前压力测量值 (整型)
*目标：读取地址为1的从机，寄存器 0x0004 (1个寄存器)*
- **主机发送**: `01 03 00 04 00 01 C5 0C`  *(注：原文档示例CRC为C5 0CB，此处修正为标准CRC16计算结果，请以实际CRC算法为准)*
- **从机响应**: `01 03 02 03 E8 B8 FA`
- **解析**: 
  - 数据字节: `03 E8` -> 大端转十进制 -> `1000`
  - 假设 `0x0003` 小数位为 2，则真实压力 = `1000 / 100 = 10.00`

### 示例 2：修改从机地址为 2 并保存
*目标：将地址 1 修改为 2*
- **步骤1：写新地址**
  - **主机发送**: `01 06 00 00 00 02 08 0B` (向 0x0000 写 0x0002)
  - **从机响应**: `01 06 00 00 00 02 08 0B` (注意：此时仍用旧地址01回复)
- **步骤2：保存到用户区**
  - **主机发送**: `02 06 00 0F 00 00 B9 FA` (注意：必须使用**新地址02**发送保存命令)
  - **从机响应**: `02 06 00 0F 00 00 B9 FA`
