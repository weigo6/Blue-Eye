# Blue-Eye 板级引脚配置说明

## 1. MCU 型号

- 主控芯片：`STM32F407VGT6`
- 工程当前外设由 `STM32CubeMX` 生成，应用代码基于 `HAL` 驱动扩展

## 2. 功能引脚分配

| 功能 | 外设/模式 | 引脚 | 说明 |
| --- | --- | --- | --- |
| 调试串口 1 | `USART2_TX` | `PA2` | 异步串口发送 |
| 调试串口 1 | `USART2_RX` | `PA3` | 异步串口接收 |
| 传感器/扩展串口 2 | `USART3_TX` | `PD8` | 异步串口发送 |
| 传感器/扩展串口 2 | `USART3_RX` | `PD9` | 异步串口接收 |
| OLED / I2C 总线 | `I2C1_SCL` | `PB6` | 硬件 I2C 时钟 |
| OLED / I2C 总线 | `I2C1_SDA` | `PB7` | 硬件 I2C 数据 |
| 状态 LED | `GPIO_Output` | `PB2` | 高电平点亮 |
| 用户按键 KEY | `GPIO_EXTI0` | `PA0` | 外部中断输入，按下为高电平 |
| SD 卡数据线 0 | `SDIO_D0` | `PC8` | SDIO 4bit 总线 |
| SD 卡数据线 1 | `SDIO_D1` | `PC9` | SDIO 4bit 总线 |
| SD 卡数据线 2 | `SDIO_D2` | `PC10` | SDIO 4bit 总线 |
| SD 卡数据线 3 | `SDIO_D3` | `PC11` | SDIO 4bit 总线 |
| SD 卡时钟 | `SDIO_CK` | `PC12` | SDIO 时钟 |
| SD 卡命令 | `SDIO_CMD` | `PD2` | SDIO 命令线 |

## 3. 按键硬件说明

- `KEY` 接在 `PA0`
- 按键一端连接 `3.3V`
- 另一端通过 `10K` 电阻下拉到地
- `PA0` 在未按下时为低电平，按下时被拉高
- 软件上采用 `EXTI0` 上升沿中断识别按下动作
- 在应用层增加 `30ms` 去抖和 `300ms` 双击判定窗口

## 4. OLED 接线约定

- 当前代码默认使用 `0.96` 寸 `128x64` 分辨率的 `SSD1306` 兼容 OLED 模块
- `VCC -> 3.3V`
- `GND -> GND`
- `SCL -> PB6`
- `SDA -> PB7`
- 默认 I2C 地址：`0x3C`

## 5. 当前界面逻辑

- 上电后进入欢迎页
- `KEY` 单击：按 `欢迎页 -> XDA 四合一传感器页 -> 压力传感器页 -> XDA 四合一传感器页...` 循环切换
- `KEY` 双击：返回欢迎页
- `XDA` 页面显示：`EC`、`TEMP`、`TDS`、`SAL` 和通信状态
- 压力页面显示：压力值、单位、原始寄存器值和通信状态
- `PB2` LED 在数据采集页点亮，在欢迎页熄灭

## 6. 当前传感器采集实现

- 已同时接入 `XDA-10F-100P-7` 四合一数字电极和 `RS485` 压力变送器 `Modbus-RTU` 采集代码
- 当前默认使用 `USART3` (`PD8/PD9`) 连接外部 `RS485` 模块
- `XDA` 传感器默认参数：从机地址 `0x02`，波特率 `9600`，数据格式 `8N1`
- `XDA` 模块现已改为固定配置模式，不再执行自动扫描地址或自动切换波特率
- 压力传感器在当前代码中按从机地址 `0x01`、波特率 `9600`、数据格式 `8N1` 进行适配
- 压力传感器地址 `0x01` 目前是按接入代码默认值配置，是否与现场设备实际地址一致仍需用户联调时确认
- 主循环会顺序轮询两个传感器模块，并分别刷新对应 OLED 页面数据
- 当前两个传感器逻辑共用 `USART3` 物理接口；若现场需要同时在线采集，需确保总线拓扑、从机地址和轮询时序匹配
- 当前实现采用主循环轮询，每 `1s` 发送一次 `Modbus-RTU` 读命令，读取 `0x0002`~`0x0004` 共 3 个寄存器
- 读取内容包括：压力单位(`0x0002`)、小数点位数(`0x0003`)、整型压力测量值(`0x0004`)
- 软件按协议中的大端格式解析 `INT16` 压力值，并结合小数点位数在 OLED 上格式化显示真实压力
- `XDA` 模块保留原有寄存器读取逻辑，用于显示 `EC`、温度、`TDS`、盐度数据
- 当前实现未接入参数写入流程；若后续需要修改地址、波特率、校验位或零位偏移，写寄存器后必须再向 `0x000F` 写入 `0x0000` 保存
- 若现场 `RS485` 收发器带有 `DE/RE` 方向控制引脚，需在后续补充该引脚定义和收发切换逻辑；当前代码默认使用自动收发的 `RS485` 模块
