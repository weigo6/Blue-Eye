# Blue-Eye 板级引脚配置说明

## 1. MCU 型号

- 主控芯片：`STM32F407VGT6`
- 工程当前外设由 `STM32CubeMX` 生成，应用代码基于 `HAL` 驱动扩展

## 2. 功能引脚分配

| 功能 | 外设/模式 | 引脚 | 说明 |
| --- | --- | --- | --- |
| 遥测串口 0 | `USART1_TX` | `PA9` | 每 `5s` 输出一帧传感器遥测数据 |
| 遥测串口 0 | `USART1_RX` | `PA10` | 预留串口接收 |
| 调试串口 1 | `USART2_TX` | `PA2` | 异步串口发送 |
| 调试串口 1 | `USART2_RX` | `PA3` | 异步串口接收 |
| 传感器/扩展串口 2 | `USART3_TX` | `PD8` | 异步串口发送 |
| 传感器/扩展串口 2 | `USART3_RX` | `PD9` | 异步串口接收 |
| OLED / I2C 总线 | `I2C1_SCL` | `PB6` | 硬件 I2C 时钟 |
| OLED / I2C 总线 | `I2C1_SDA` | `PB7` | 硬件 I2C 数据 |
| 状态 LED | `GPIO_Output` | `PB2` | 高电平点亮 |
| 用户按键 KEY | `GPIO_EXTI0` | `PA0` | 外部中断输入，按下为高电平 |
| SD 卡数据线 0 | `SDIO_D0` | `PC8` | SDIO 4bit 总线 |
| SD 卡数据线 1 | `SDIO_D1` | `PC9` | SDIO 4bit 总线 |
| SD 卡数据线 2 | `SDIO_D2` | `PC10` | SDIO 4bit 总线 |
| SD 卡数据线 3 | `SDIO_D3` | `PC11` | SDIO 4bit 总线 |
| SD 卡时钟 | `SDIO_CK` | `PC12` | SDIO 时钟 |
| SD 卡命令 | `SDIO_CMD` | `PD2` | SDIO 命令线 |
| SD 卡检测 | `GPIO_Input` | `PD3` | 低电平表示已插卡 |

## 3. 按键硬件说明

- `KEY` 接在 `PA0`
- 按键一端连接 `3.3V`
- 另一端通过 `10K` 电阻下拉到地
- `PA0` 在未按下时为低电平，按下时被拉高
- 软件上采用 `EXTI0` 双边沿中断识别按下与释放动作
- 在应用层增加 `30ms` 去抖、`700ms` 页面长按和 `3000ms` SD 安全卸载长按判定

## 4. OLED 接线约定

- 当前代码默认使用 `0.96` 寸 `128x64` 分辨率的 `SSD1306` 兼容 OLED 模块
- `VCC -> 3.3V`
- `GND -> GND`
- `SCL -> PB6`
- `SDA -> PB7`
- 默认 I2C 地址：`0x3C`

## 5. 当前界面逻辑

- 上电后进入欢迎页
- `KEY` 单击：按 `欢迎页 -> XDA 四合一传感器页 -> 压力传感器页 -> UART CONFIG -> SD LOGGER -> 欢迎页...` 循环切换
- `KEY` 长按：在当前功能页执行附加功能；当前在压力页切换 `RAW` / `FLOAT` 采集显示模式，在 `UART CONFIG` 页切换 `USART1` 周期输出开关
- `SD LOGGER` 页面持续按键 `3s`：发起安全卸载；`SAFE TO REMOVE` 或非格式类 `ERROR` 状态下再次长按可重新初始化并恢复记录
- `XDA` 页面显示：`EC`、`TEMP`、`TDS`、`SAL` 和通信状态
- 压力页面显示：压力值、单位、原始寄存器值和通信状态
- `UART CONFIG` 页面显示：`USART1` 周期输出开关状态和发送计数
- `SD LOGGER` 页面显示：挂载/写入/卸载状态、当前文件、队列深度和错误码
- `PB2` LED 在数据采集页点亮，在欢迎页熄灭

## 6. 当前传感器采集实现

- 已同时接入 `XDA-10F-100P-7` 四合一数字电极和 `RS485` 压力变送器 `Modbus-RTU` 采集代码
- 当前默认使用 `USART3` (`PD8/PD9`) 连接外部 `RS485` 模块
- 当前新增 `USART1` (`PA9/PA10`) 作为对外遥测串口，每 `5s` 输出一次最新采集快照
- `XDA` 传感器默认参数：从机地址 `0x02`，波特率 `9600`，数据格式 `8N1`
- `XDA` 模块现已改为固定配置模式，不再执行自动扫描地址或自动切换波特率
- 压力传感器在当前代码中按从机地址 `0x01`、波特率 `9600`、数据格式 `8N1` 进行适配
- 压力传感器地址 `0x01` 目前是按接入代码默认值配置，是否与现场设备实际地址一致仍需用户联调时确认
- 两个传感器适配层不直接操作 UART，而是把请求提交给唯一的 `ModbusBus` 总线所有者，由它完成仲裁、CRC、超时和结果分发
- 当前两个传感器逻辑共用 `USART3` 物理接口；若现场需要同时在线采集，需确保总线拓扑和从机地址匹配，软件会串行化所有请求并保留 Modbus RTU 帧间隔
- 当前实现采用主循环驱动的完整非阻塞状态机；每个传感器约每 `1s` 尝试发起一次轮询，发送使用 `USART IT`，发送完成中断内立即启动 Receive-to-IDLE DMA
- `TIM6` 以 `1s` 周期请求主循环检查绝对截止时间；调度器使用 `next_deadline += 5000 ms` 产生 5 秒事件，避免相对延时累积漂移
- 若同步操作跨过多个截止点，恢复后只构建最新截止点的一份快照，并累计错过周期；不会再根据积压事件数快速生成多条近似快照
- 5 秒事件到达后构建一份传感器快照，同时提交给 `USART1` 遥测任务和 SD 日志队列
- `USART1` 周期遥测当前使用异步 `DMA TX + 中断完成` 发送，繁忙时合并为最新待发快照
- `USART3` 传感器通信当前使用完整非阻塞状态机：`TX IT -> TX 完成后立即启动 RX DMA -> IDLE/长度完成 -> CRC/异常/超时处理`
- 压力页默认工作在 `RAW` 模式，读取 `0x0002`~`0x0004` 共 3 个寄存器
- `RAW` 模式读取内容包括：压力单位(`0x0002`)、小数点位数(`0x0003`)、整型压力测量值(`0x0004`)
- 压力页长按切换到 `FLOAT` 模式后，读取压力单位(`0x0002`) 和浮点压力值(`0x0016`~`0x0017`)
- 软件按协议中的大端格式解析 `INT16` 压力值，并结合小数点位数在 OLED 上格式化显示真实压力；浮点模式则直接显示 `Float32` 解析结果
- `XDA` 模块保留原有寄存器读取逻辑，用于显示 `EC`、温度、`TDS`、盐度数据
- 当前应用层使用 `sd_logger` 独占 FatFs，日志写入 `0:/LOG/LOGxxxxx.BIN`
- 日志使用 128 条 RAM 队列，每 8 条 64 字节记录组成一个 512 字节写入
- 单个日志文件约 `32 MiB` 后顺序创建下一个文件，不覆盖已有历史文件
- 有新数据写入时最长约每 `120s` 执行一次文件同步
- 安全卸载会停止新记录入队、排空队列、同步、关闭文件并卸载；只有显示 `SAFE TO REMOVE` 后才允许拔卡
- FatFs 通用驱动会在底层返回 `STA_NOINIT` 时清除初始化缓存，确保安全卸载或拔插卡后的下一次挂载真正重新初始化 SD 卡
- 仅支持 FAT32，不自动格式化卡；当前尚无有效 RTC，记录使用 `HAL_GetTick()`
- `SDIO` 数据时钟仍使用 `ClockDiv=4`，由 `48 MHz` 内核时钟分频得到约 `8 MHz`
- `SDIO_RX` 保留在 `DMA2_Stream6`，`SDIO_TX` 保留在 `DMA2_Stream3`，两个 DMA 中断抢占优先级均为 `3`
- `SDIO_IRQn` 保持启用，抢占优先级为 `4`
- `USART1` 遥测采用 ASCII 帧协议：`$` 起始，`,` 分隔，`*XX` 为异或校验，`\r\n` 结束
- `USART1` 周期输出可在 `UART CONFIG` 页面单独关闭
- 遥测字段依次输出系统节拍、压力状态与数值以及 XDA 状态与数值；原 SD 日志统计字段已移除
- 当前实现未接入参数写入流程；若后续需要修改地址、波特率、校验位或零位偏移，写寄存器后必须再向 `0x000F` 写入 `0x0000` 保存
- 若现场 `RS485` 收发器带有 `DE/RE` 方向控制引脚，需在后续补充该引脚定义和收发切换逻辑；当前代码默认使用自动收发的 `RS485` 模块

## 7. CubeMX 配置要点

- `USART1`
- 模式：`Asynchronous`
- 参数：`9600 8N1`
- DMA：开启 `USART1_TX`
- 中断：开启 `USART1 global interrupt`、`DMA2_Stream7_IRQn`

- `USART3`
- 模式：`Asynchronous`
- 参数：`9600 8N1`
- DMA：开启 `USART3_RX`
- 中断：开启 `USART3 global interrupt`、`DMA1_Stream1_IRQn`

- `SDIO`
- 总线：`4-bit SDIO`
- 时钟：`ClockDiv=4`，`SDIO_CK` 约为 `8 MHz`
- DMA：同时开启 `SDIO_RX` 和 `SDIO_TX`
- 推荐流：`DMA2_Stream6` 作为 `RX`，`DMA2_Stream3` 作为 `TX`
- 中断：开启 `SDIO_IRQn`、`DMA2_Stream6_IRQn`、`DMA2_Stream3_IRQn`；RX/TX DMA 抢占优先级为 `3`，SDIO 全局中断抢占优先级为 `4`

- `TIM6`
- 时基：`Internal Clock`
- 当前参数：`PSC=15999`、`ARR=999`
- 中断：开启 `TIM6_DAC_IRQn`
- 用途：每秒唤醒绝对截止时间检查，遥测周期由 `HAL_GetTick()` 的 5000 ms 截止点确定，而不是累计待处理事件数量

- `I2C1`
- 当前仅用于 OLED，保留普通主机发送即可
- 现阶段不建议开启 DMA，原因是 OLED 刷新频率低、DMA 收益有限且会增加同步复杂度
